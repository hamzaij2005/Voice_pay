
==============================================================
  VoicePay — Complete Setup & Run Guide
==============================================================

──────────────────────────────────────────────────────────────
  STEP 0 — Install everything (run once)
──────────────────────────────────────────────────────────────

  pip install flask twilio gTTS requests groq openai-whisper soundfile numpy sounddevice

  Also install ffmpeg (required by gTTS/pydub):
    Download: https://www.gyan.dev/ffmpeg/builds/
    → ffmpeg-release-essentials.zip
    → Extract → copy ffmpeg.exe to C:\Windows\System32\
    OR add the bin folder to your system PATH

──────────────────────────────────────────────────────────────
  STEP 1 — Set environment variables (every new terminal)
──────────────────────────────────────────────────────────────

  PowerShell (run all of these):

    $env:GROQ_API_KEY          = "gsk_your_groq_key_here"
    $env:TWILIO_ACCOUNT_SID    = "ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
    $env:TWILIO_AUTH_TOKEN     = "your_auth_token_here"
    $env:TWILIO_PHONE_NUMBER   = "+1xxxxxxxxxx"
    $env:BACKEND_URL           = "http://localhost:5000/process"

  Where to find your Twilio values:
    → Login at console.twilio.com
    → Dashboard → Account SID and Auth Token are shown on homepage
    → Phone Numbers → Manage → Active Numbers → your number

──────────────────────────────────────────────────────────────
  STEP 2 — Run all 3 parts (3 separate terminals)
──────────────────────────────────────────────────────────────

  Terminal 1 — Member 3 backend:
    python app.py
    → Should say: Running on http://localhost:5000

  Terminal 2 — Member 1 voice engine:
    python twilio_app.py
    → Should say: Running on http://localhost:5001

  Terminal 3 — ngrok tunnel:
    ngrok http 5001
    → Copy the Forwarding URL e.g: https://abc123.ngrok-free.app

──────────────────────────────────────────────────────────────
  STEP 3 — Connect Twilio to ngrok
──────────────────────────────────────────────────────────────

  1. Go to: https://console.twilio.com
  2. Phone Numbers → Manage → Active Numbers
  3. Click your phone number
  4. Scroll to "Voice Configuration"
  5. Set "A call comes in" → Webhook
  6. URL: https://abc123.ngrok-free.app/incoming   ← your ngrok URL
  7. Method: HTTP POST
  8. Click Save

──────────────────────────────────────────────────────────────
  STEP 4 — Test independently (Member 1 test, no AI needed)
──────────────────────────────────────────────────────────────

  With twilio_app.py running, open browser:
    http://localhost:5001/test_voice

  You will see TwiML XML — this is what Twilio reads to play voice.
  To HEAR it, set this URL as your Twilio webhook and call your number.

  Expected call flow for independent test:
    → "Welcome to VoicePay. Running independent test."
    → "Transaction successful. 500 rupees have been sent to Ali..."
    → "Test complete. Voice system is working correctly."
    → Call ends

──────────────────────────────────────────────────────────────
  STEP 5 — Full integrated call flow
──────────────────────────────────────────────────────────────

  Call your Twilio number. The call will:

    [Twilio] → [ngrok] → [twilio_app.py :5001] → [app.py :5000]

  Flow:
    1. "Welcome to VoicePay. Please say your username."
       → You say: "ahmed"

    2. "Thank you ahmed. Please enter your 4 digit PIN using the keypad."
       → You press: 1 2 3 4

    3. "PIN received. Please say your command."
       → You say: "Send 500 rupees to Ali"
             OR: "Check my balance"
             OR: "Ali ko 500 bhejo"

    4. Groq extracts intent → app.py processes → result spoken back:
       → "500 rupees sent to Ali successfully. Your new balance is 1500 rupees."

    5. "Would you like another transaction? Press 1 for yes or hang up."
